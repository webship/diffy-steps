# @webship-js/diffy-steps documentation

Per-step reference for the `@webship-js/diffy-steps` plugin for [webship-js](https://www.npmjs.com/package/webship-js).

Start with the [root README](../README.md) for installation, configuration, and the environment-variable table. The [step-definitions README](../tests/step-definitions/README.md) carries the deep reference: the adoption walkthrough, the notes on the Diffy API contract, the Diffy-side IP allow-list, and links into Diffy's own documentation.

## Source layout

```
diffy-steps/
├── docs/steps/                 one page per step, generated by npm run docs
├── examples/diffy/             baseline and changed example pages
└── tests/
    ├── features/               reference scenarios, run in both lanes
    ├── step-definitions/       the published pack
    │   ├── diffy.steps.js      the steps
    │   ├── diffy-client.js     the Diffy API client
    │   └── diffy-images.js     image helpers
    ├── support/                the test project's own support code: the mock
    │   └── mock-diffy-api/     Diffy API, the example site and the lane hooks
    ├── unit/                   tests of the mock and the client
    ├── tools/                  docblock reader shared by the two scripts below
    ├── check-examples.js       npm run test:examples
    └── generate-docs.js        npm run docs, npm run docs:check
```

Only the three files in `tests/step-definitions/` (plus `README.md` and `LICENSE`) are published to npm. Everything else is this repository's own test project.
